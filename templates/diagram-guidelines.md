# Figure Brief Template

For each technical figure record:
- Figure ID and case ID
- Figure purpose: what engineering question it must answer
- Figure type
- Source IDs
- Confirmed geometry/data
- Explicitly unknown geometry/data that must not be invented
- Labels and callouts
- Required force/water/movement arrows
- Alt text

A figure passes only when it communicates mechanism at normal publication size without relying on decorative imagery.
