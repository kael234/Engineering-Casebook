# Source Standard

## Authority tiers
- **A:** official investigation, government/transport report, standard, peer-reviewed case history.
- **B:** recognised engineering institution, authoritative project paper, conference paper by responsible specialists.
- **C:** technical trade publication or engineering journalism; context/discovery only unless independently supported.
- **D:** general news, blogs, forums, video; leads only.

## Minimum evidence
### Deep Dive
At least one Tier A primary source. Prefer one independent supporting source. Key numerical claims must be cited.

### Other cases
At least one Tier A or strong Tier B source. If the case relies mainly on a project-authored paper, state that limitation visibly.

### Product cases
Use the incident/investigation source plus manufacturer, approval or standard documentation where useful. Marketing copy is not independent evidence.

## Copyright
Store metadata and links by default. Commit complete external reports only when public-domain, open-licensed or redistribution is clearly permitted.

## Citation notation
Canonical Markdown uses stable IDs such as `[@SRC-0012]`. The issue renderer may present compact numbered source markers and clickable links.
