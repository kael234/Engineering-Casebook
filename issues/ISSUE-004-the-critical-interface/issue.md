# Engineering Casebook 004 - The Critical Interface

Accepted three-page v2 magazine edition. Cases: I-35W gusset plates; Mumbai-Pune basalt rockfall; stainless-steel pool-building SCC; SFO friction-pendulum isolation; Brevoort Island Arctic hydrocarbon barrier.

## Thread
Interfaces are structures. A gusset, rock joint, humid ceiling, sliding bearing or liner seam can govern the system while the obvious main member remains respectable.
