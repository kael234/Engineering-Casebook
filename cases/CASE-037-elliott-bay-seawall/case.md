# Executive Summary
Seattle's replacement Elliott Bay Seawall addressed a system in which loose waterfront fill was vulnerable to earthquake-induced liquefaction. The project used jet grouting to create a cellular block of improved soil extending to firmer glacial soils, providing a structural spine behind the new seawall face. [@SRC-0050] [@SRC-0051]

# Engineering Mechanism
Jet grouting mixes in-situ soil with grout to form improved columns. Seattle project documentation describes the columns arranged in a grid or honeycomb pattern, enclosing otherwise liquefiable soil. An SDOT construction update described approximately 6,000 columns and 3.1 million cubic feet of grout. [@SRC-0051]

# Evidence Gap
The case does not claim observed earthquake performance after construction, and it does not infer design strengths, column diameters or acceptance criteria that were not extracted from the cited project documentation.

# Engineer's Notebook
