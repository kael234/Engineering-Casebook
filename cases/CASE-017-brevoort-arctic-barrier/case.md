# Executive Summary
A remote Arctic radar site required a short-season barrier to intercept hydrocarbon migration near the groundwater table above permafrost. The documented system used a fluorinated HDPE geomembrane plus geosynthetic clay liner and field-adapted sealing details. [@SRC-0023]

# Toolbox
The case history documents GSE HDPE fluorinated by Fluoro-Seal, Bentofix Thermal Lock NWL GCL, Sika Arctic Grout with bentonite and Layfield RPE 25 cover. These names belong in the Casebook because the source explicitly identifies them.

# Engineer's Notebook
Robust barriers use redundancy by mechanism: low-permeability transport control, local-defect backup, recharge reduction and a bottom detail that closes the bypass route.
