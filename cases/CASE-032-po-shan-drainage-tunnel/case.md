# Executive Summary
At Po Shan in Hong Kong, high groundwater had long been recognised as a major slope-safety concern. Horizontal drains installed in the 1980s lowered groundwater, but monitoring in the early 2000s showed declining discharge from some drains and locally high groundwater during heavy rain. GEO responded with a larger groundwater-regulation system rather than assuming the earlier drains would remain permanently effective. [@SRC-0041]

# Engineering Mechanism
The Po Shan system uses two 3.5 m diameter drainage tunnels with a combined length of 500 m, a network of 172 sub-vertical drains and automatic real-time groundwater monitoring. The tunnels provide durable access and collection routes from which drains can intercept groundwater within the hillside. Monitoring closes the loop by showing whether the hydraulic objective continues to be achieved. [@SRC-0041]

# Evidence Gap
The available government project page documents the system configuration and its risk-reduction purpose but is not an independent peer-reviewed performance audit. The case therefore treats Po Shan as a documented design and monitoring strategy, not proof that the same tunnel geometry is appropriate elsewhere.

# Engineer's Notebook
Groundwater control is a maintained system, not a one-time hole in the slope. Provide a collection path, an outlet, access for upkeep and monitoring that can reveal when performance changes.
