# Executive Summary
A handrail post fell from height after a proprietary concrete/masonry anchor screw failed. CROSS reported that manufacturer's installation guidance had not been followed, including requirements affecting hole preparation, installation and reuse. [@SRC-0007]

# Engineer's Notebook
The design resistance belongs to the installed fixing system, not the object in the box. Safety-critical anchor specifications should control product, substrate, embedment, hole preparation, installation and verification.
